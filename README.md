# Expense Tracker CLI
A terminal-based Expense Tracker application built using Python.

## Features
* Log expenses with amount, category, and remarks
* View all recorded expenses
* Filter expenses by date or category
* Monthly expense report with per-category breakdown
* Persistent storage using Python's json module

## Concepts Used
* Functions
* Lists and Dictionaries
* File Handling
* Data Persistence with JSON
* Loops and Conditionals

## How to Run
```bash
python main.py
```

## Future Improvements
* Export reports to CSV
* Edit or delete existing expenses
* Add graphical insights using matplotlib
